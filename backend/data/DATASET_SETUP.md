# UNSW-NB15 Intrusion Detection Dataset Setup Guide

## 1. Overview
The **UNSW-NB15** dataset is a comprehensive network intrusion detection benchmark generated by the Cyber Range Lab of UNSW Canberra (Australian Centre for Cyber Security, ACCS). It comprises modern benign normal activities and synthesized contemporary attack behaviors, capturing 49 flow features spanning flow duration, protocols, packet sizes, TTLs, TCP window parameters, jitter, and transaction metrics.

- **Official Source**: [UNSW Canberra Research Project](https://research.unsw.edu.au/projects/unsw-nb15-dataset)
- **Primary Reference**: Moustafa, Nour, and Jill Slay. "UNSW-NB15: a comprehensive data set for network intrusion detection systems (UNSW-NB15 network data set)." *2015 Military Communications and Information Systems Conference (MilCIS)*. IEEE, 2015.

---

## 2. Official Download Instructions

If the dataset is not yet present on your system, obtain the standardized pre-partitioned CSV files:

1. **Direct Download Links (Official Academic Repository)**:
   - Training Set: `UNSW_NB15_training-set.csv` (~32 MB, 175,341 records)
   - Testing Set: `UNSW_NB15_testing-set.csv` (~15 MB, 82,332 records)
2. Place both CSV files into the `backend/data/` directory:
   ```text
   omen/
   └── backend/
       └── data/
           ├── DATASET_SETUP.md
           ├── UNSW_NB15_training-set.csv
           └── UNSW_NB15_testing-set.csv
   ```
3. Verify that the files exist using PowerShell:
   ```powershell
   Get-ChildItem -Path "backend/data/UNSW_NB15_*.csv"
   ```

## 3. Data Schema & Leakage Shields

The dataset contains 45 columns:
- **Identifier**: `id` — Unique row ID. **CRITICAL LEAKAGE SHIELD**: Dropped unconditionally before any preprocessing.
- **Categorical Network Metadata**: `proto` (protocol e.g. tcp, udp), `service` (application service e.g. http, dns, -), `state` (connection state e.g. FIN, CON, INT).
- **Target Columns**:
  - `label`: Binary classification target (0: Normal/Benign, 1: Malicious Attack).
  - `attack_cat`: Multi-class attack taxonomy (`Normal`, `Generic`, `Exploits`, `Fuzzers`, `DoS`, `Reconnaissance`, `Analysis`, `Backdoor`, `Shellcode`, `Worms`).
- **Feature Separation**: Target columns (`label`, `attack_cat`) are strictly isolated from the training feature matrix $X$.
- **Preprocessing Pipeline**: All standard scalers and categorical encoders are fit **strictly** on the training partition to prevent test-set data leakage.
